## Artwork

The city itself is drawn procedurally at runtime from the primitives in
`apps/city/src/render` — the palette derives three shades per material from a
single fixed light direction, and shapes are baked to an offscreen canvas per
variant and blitted. Every sprite, tile and building on the map is generated
this way, and none of it is a third-party asset.

### Raster images

Three PNGs live in `apps/city/public/crew` and are the only bitmap artwork in
the repository:

- `effort-low.png`
- `effort-medium.png`
- `effort-high.png`

They illustrate the thinking-effort levels in the dispatch dialog. This file
previously said the repository contained no image assets at all, which stopped
being true when they were added; the statement above is narrowed to the map,
which is what it was really describing.

**Provenance to be confirmed by the repository owner before release.** These
were contributed as finished files rather than generated by anything in this
repository, so nothing here can establish where they came from, and an
attribution file is the wrong place to guess. If they are original work, say so
here; if they derive from anything licensed, its terms belong here too.

Any third-party art added later must be listed here with its licence before it
is merged.

## Dependencies

Third-party runtime and build dependencies are declared in the workspace
`package.json` files and pinned in `pnpm-lock.yaml`, each under its own licence.
Notable ones: [TrueForge](https://github.com/truefoundry/trueforge) (the agent
harness this is built on), the Model Context Protocol TypeScript SDK, React, and
Vite.
